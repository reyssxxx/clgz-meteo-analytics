# Метеоданные Центрально-Лесного заповедника — данные для хакатона

Срочные наблюдения автоматических метеостанций урочища «Красное», приведённые к единому формату. Значения не исправлялись и не восстанавливались: ошибочные помечены флагами, пропуски оставлены пропусками.

## Состав

```
data/ame60/ame60_ГГГГ.csv     АМЕ-60, 1992–2021 (27 файлов; 2000–2002 нет)
data/sokol_m1/kr1_ГГГГ.csv    Сокол М1, Кр1 (поляна): 2022–2025
data/sokol_m1/kr2_ГГГГ.csv    Сокол М1, Кр2 (поле):   2022–2025
coverage_by_month.csv         валидные дни и валидность каждого месяца по станциям и годам
```

**АМЕ-60 и Сокол М1 — разные приборы на разных точках, без периода совместной работы. Ряды не объединять, тренды через 2021/2022 не строить.**

## Колонки

| Колонка | Что это | Единица | Где есть |
|---|---|---|---|
| `datetime` | срок наблюдения, `ГГГГ-ММ-ДД ЧЧ:ММ` | — | везде |
| `t_air` | температура воздуха | °C | везде |
| `rh` | относительная влажность | % | везде |
| `wind_speed` | средняя скорость ветра за интервал | м/с | везде |
| `wind_gust` | максимальная скорость ветра (порыв) | м/с | везде |
| `wind_dir` | направление ветра | градусы, 0–360 | везде, кроме АМЕ-60 1998 |
| `soil_05`, `soil_10`, `soil_20` | температура почвы на 5, 10, 20 см | °C | только АМЕ-60 |
| `pressure_hpa` | атмосферное давление | гПа | только Сокол М1 |
| `qc_flag` | флаги качества (см. ниже) | — | везде |

- Шаг: АМЕ-60 — 15 минут (96 сроков в сутки); Сокол М1 — 60 минут в 2022–2023, преимущественно 30 минут с нерегулярными интервалами в 2024, смешанный 30/60 минут в 2025.
- Время записано так, как в исходных файлах станций. Часовой пояс заказчиком не подтверждён.
- Если параметр в каком-то году не измерялся, колонки нет (например, `wind_dir` в 1998).

## Флаги качества (`qc_flag`)

Флаги перечисляются через `;`. Флаг относится к конкретному параметру, а не ко всей строке:

| Флаг | Значение |
|---|---|
| `<параметр>:range` | значение вне физически возможного диапазона: t_air −50…45 °C; rh 0–100 %; wind_speed 0–60 м/с; wind_gust 0–75 м/с; wind_dir 0–360°; почва −40…45 °C; давление 940–1050 гПа |
| `soil_05:fault` | сбой датчика почвы 5 см: значение ниже −15 °C при положительной температуре воздуха (в основном 2016–2017) |
| `wind_dir:fault` | направление ветра в 2021 году недостоверно целиком (в этом году почти все значения больше 360°) |
| `dup_conflict` | в исходном файле на этот срок несколько строк с разными значениями. **Такие строки не используются целиком** |

Правило: значение параметра, указанного во флаге, в расчёт не входит; остальные параметры той же строки используются. Строки с `dup_conflict` не используются.

## Правила расчёта

- **Сутки валидны** (учитываются в расчётах), если за них есть не менее 75% сроков: для АМЕ-60 — не менее 72 из 96; для Сокол М1 — данные не менее чем за 18 часов из 24.
- **Месяц валиден**, если пропущено (невалидно) не более 10 дней и нет 5 и более пропущенных дней подряд.
- Среднесуточное значение — среднее по всем срокам за сутки.
- Декады: 1–10, 11–20, 21-е — последний день месяца.
- Среднее по многолетнему ряду называется «среднее за выбранный период» (не «климатическая норма») и показывается вместе с числом лет. Норму по стандарту ВМО (24 года из 30) по этим данным не набрать: для января валидных лет около 14 из 30.

## Известные проблемы

- **Пропуск АМЕ-60 с 4 января 1999 по 17 августа 2003.** За 1999 есть только 1–3 января, за 2000–2002 данных нет.
- **1992:** станция начала работу 1 июля.
- **1998:** не измерялось направление ветра.
- **2016–2017:** сбой датчика почвы 5 см (около 12,5 тыс. значений помечены).
- **2017–2021:** станция работала с перебоями, особенно зимой; 2019 — до 5 октября, 2020 — с 19 апреля по 1 ноября, 2021 — с 5 января по 6 ноября.
- **2021:** направление ветра недостоверно целиком.
- **Сокол М1, Кр2, 2022–2023:** давление часто вне физических пределов (помечено).
- **Сокол М1, 2023:** Кр1 — только по 26 апреля, Кр2 — около 25 дней.
- Сроки Сокол М1 отсортированы по возрастанию. В 2024 году записи не привязаны к началу получаса или часа: время не округлялось.

## Что исключено из исходных файлов и почему

- **Осадки:** у АМЕ-60 единица не подтверждена (1992–1998) и с 2003 года значения похожи на шум; у Сокол М1 суммы неправдоподобные.
- **Солнечная радиация** (`Glob-rad`, `Power` у АМЕ-60): смысл и единицы колонок не подтверждены.
- Суточные сводки, итоговые строки со средними, пустые строки, точные дубли сроков (несколько сотен в 1994–1998).


## Добавление 2024 года и проверка набора

- `kr1_2024.csv` получен из `2024_Kr1_ready.xlsx` (лист `Kr_1_24`), `kr2_2024.csv` — из `2024_Kr2_ready.csv`. Изменены формат записи даты и заголовки, сами сроки и числовые значения не исправлялись. Дубликатов сроков за 2024 год нет.

Если считать для давления только часы с неотмеченным значением, проходят 334 дня и 11 месяцев (апрель не проходит). Остальные параметры этих строк не исключаются.

- Покрытие станции пересчитано по календарным дням: для АМЕ-60 считаются уникальные записанные сроки, для Сокол М1 — уникальные часы (не строки), конфликтные строки исключаются. Месяц проверяется отдельно по двум порогам из правил. Все 396 строк покрытия за прежние годы совпали с исходным архивом; добавлены 24 строки за 2024 год.
