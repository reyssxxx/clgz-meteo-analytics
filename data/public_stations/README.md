# Открытые данные метеостанций NOAA

Снимок GHCN Daily за 2024–2025 годы для двух станций. Данные используются в каталоге на странице «Данные и отчёты».

- Нью-Йорк, Центральный парк — [USW00094728](https://www.ncei.noaa.gov/data/global-historical-climatology-network-daily/access/USW00094728.csv)
- Бостон, аэропорт Логан — [USW00014739](https://www.ncei.noaa.gov/data/global-historical-climatology-network-daily/access/USW00014739.csv)

Оставлены TAVG, TMAX, TMIN и PRCP. Температура переведена из десятых долей °C в °C, осадки из десятых долей мм в мм. Значения с флагом качества NOAA и отсутствующие значения оставлены пустыми. [Описание GHCN Daily](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily)
